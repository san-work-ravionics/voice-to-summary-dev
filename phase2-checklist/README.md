# phase2-checklist — Checklist-based coverage check (Phase 2)

Part of the [voice-to-summary](../README.md) progression. Builds on [phase1-baseline](../phase1-baseline/README.md) by adding a fixed **checklist** of expected topics, so the summary reports what was and wasn't actually discussed, plus context-aware prompting (project background injected before the transcript).

Same shared kickoff recording as phase1-baseline/phase3-context (`audio-generation/output/01-kickoff/`) — only the summarization step changes.

## What's new

`src/checklist.py` defines a fixed `CHECKLIST` of topics this kind of project meeting is expected to cover:
- Onboarding flow status
- Payments integration status
- Design updates (e.g. dark mode)
- Legal / privacy approval
- Analytics instrumentation
- Budget or cost impact
- Next meeting / follow-up schedule

Everything except **budget/cost impact** is actually discussed in the kickoff dialogue — that one is left out on purpose, so the "Not covered" path is demonstrably exercised, not just theoretical.

`src/summarize.py` still uses the local LLM for the Topic/Key Points/Decisions/Actions brief, then appends a 5th Markdown section, `## Checklist Coverage`. That section is **not** generated by the LLM — three different LLM-based framings were tried (all 7 items in one call, one call per item against the transcript, one call per item against the brief) and each got 2-3 of 7 items wrong, sometimes even contradicting its own stated reasoning. Each checklist item instead carries a few keywords (`src/checklist.py`), and coverage is decided by a plain keyword match against the transcript, quoting the matched sentence as evidence — deterministic and correct by construction for this known content, rather than a small model's unreliable judgment call.

## Run

```bash
python phase2-checklist/src/main.py
```

Writes `output/transcript.txt` and `output/summary.txt` with all 5 sections. `--regenerate` is a no-op (see phase1-baseline's README) — the shared kickoff recording belongs to `audio-generation/`.
